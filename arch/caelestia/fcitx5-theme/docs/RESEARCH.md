# Environment research and choice

The read only inspection took place on Arch Linux in a Wayland/Hyprland session. Installed packages included Fcitx5 5.1.22, fcitx5-mozc 3.34.6239.2, fcitx5-configtool 5.1.15, fcitx5-gtk 5.1.7, fcitx5-qt 5.1.15, Caelestia Shell 2.4.0, Caelestia CLI 1.1.2, Quickshell 0.3.1, Hyprland 0.56.2, and Qt 6.11.2. IBus was absent. The Fcitx5 profile names Mozc as its default input method; `QT_IM_MODULE=fcitx` and `XMODIFIERS=@im=fcitx` were set. The live Fcitx5 D-Bus connection and Hyprland control socket were inaccessible during inspection, so the currently drawn popup could not be observed directly.

The installed Caelestia `Colours.qml` watches the CLI generated `${XDG_STATE_HOME:-$HOME/.local/state}/caelestia/scheme.json`. The file has `mode` and a `colours` map with Material style fields such as `surfaceContainer`, `onSurface`, and `primaryContainer`. Caelestia's user configuration enables transparency. Its UI uses rounding tokens and a `RectangularShadow` effect; these are internal QML features, not a Fcitx5 theme API. Caelestia also requests a Hyprland layer blur rule for its own drawer namespace. That rule does not directly establish blur for a Fcitx5 input popup.

| Approach | Feasibility | Constraint and risk |
| --- | --- | --- |
| Fcitx5 Classic UI theme | Chosen. Supports role based colours, number and comment colours, image backgrounds, alpha, nine slice corners, blur request, and existing candidate handling. | Compositor decides actual blur. Font and layout stay in Classic UI config. Images must be regenerated when the scheme changes. |
| Kimpanel frontend | Possible through a separate panel implementation. | Needs protocol integration and different Wayland placement and focus testing. Can conflict with the Classic UI selection. |
| Custom Qt/QML panel | Technically possible as a new Fcitx5 UI frontend. | Requires another process or addon, extra Qt dependencies, event and focus plumbing, and significantly more maintenance. |

Wayland clients do not place popup surfaces freely. Fcitx5's existing Classic UI uses the appropriate input popup surface for a `wayland_v2` input context, keeps keyboard focus with the application, and handles candidate clicks and paging. Its 5.1.22 source also has an `EnableBlur` request path for a background effect protocol. Hyprland must support and honour that protocol at runtime; alpha in the PNG alone produces only translucency. The baked image shadow works without compositor support. A report of SVG nine slice artifacts on Fcitx5 5.1.22 led to PNG assets for this project.
