# Personal Development Preferences

## Git

- Never run `git commit`.
- Never run `git push`.
- I handle commits and pushes myself.
- You may inspect Git status and diffs when useful.
- Do not rewrite Git history unless I explicitly ask.

## Coding

- You may inspect, edit, build, lint, and test code.
- Before making large or architectural changes, explain the proposed approach first.
- Do not make unrelated changes.
- Prefer small, focused changes over unnecessary rewrites.

## Explanations

- When I ask about code, prioritize helping me understand it.
- Explain why the code works, not only what it does.
- When suggesting a change, explain the reason and trade-offs.
- Use technical terminology where appropriate, but explain unfamiliar concepts clearly.

## Workflow

- For substantial tasks, first inspect the relevant code and explain your understanding.
- If there are multiple reasonable approaches, present the main options before implementing.
- After editing, summarize what changed and why.
